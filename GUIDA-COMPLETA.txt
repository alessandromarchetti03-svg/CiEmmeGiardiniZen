Nei file che hanno il cookie banner (articoli.html, portfolio.html, 
articolo1.html+duplicati), trova il JavaScript e sostituisci:

PRIMA:
```javascript
script.src = 'https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX'
gtag('config', 'G-XXXXXXXXXX');
meta.content = 'XXXXXXXXXXXXX';
```

DOPO (con i TUOI dati):
```javascript
script.src = 'https://www.googletagmanager.com/gtag/js?id=G-TUOIDID'
gtag('config', 'G-TUOIDID');
meta.content = 'TUOTOKEN_VERIFICA';
```

Come trovare i tuoi dati:
1. Google Analytics: Impostazioni → ID Proprietà (G-...)
2. Google Search Console: Verifica proprietà → Token (in <meta>)

  3. Il sito mostra placeholder se foto manca

Problem: Cookie banner non scompare
Solution:
  1. Testa in finestra privata/incognito
  2. Clearare localStorage del browser
  3. Prova il bottone "Accetta tutto"

Problem: Menu hamburger non funziona
Solution:
  1. Assicurati di essere su mobile (≤768px)
  2. JavaScript abilitato nel browser
  3. Controlla la console per errori

Problem: Link non funzionano
Solution:
  1. Verifica che i file siano nella stessa cartella

   Il sito NON richiede librerie JavaScript.
